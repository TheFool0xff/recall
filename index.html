BRING YOUR COMMANDS WITH YOU

Import commands

Import a Recall JSON export, paste LLM-formatted JSON, or add one command per line from your history.

JSON preserves multiline commands and descriptions. Plain text treats each nonblank line as a separate command and strips numeric history prefixes. Existing identical commands are skipped.

Take your library with you

Download every command, description, note, and favorite as a JSON backup. Import it on another device to continue where you left off.

Want it in your GitHub repo?

Download the repository file and replace library.json in your repo. It becomes the starting collection on browsers without a saved library. On devices already using Recall, import the file to merge new commands.

Anything committed to a published site can be downloaded by its visitors. Only include commands and notes you intend to publish.

NEW

Organize in a few clicks.

Create or rename collections with the + beside Collections. Select commands to move, tag, or delete them together. Switch between compact rows and cards, group by collection or platform, and collapse sections. Undo restores the last edit in this session.

01

Paste now. Explain later.

Add a command with an optional title, collection, and tags. Copy an explanation prompt, use your preferred LLM, and paste the result into the description.

02

Find the thing you half-remember.

Search matches titles, commands, descriptions, notes, and tags. Try nmap service. Combine search with a collection or platform filter.

03

Make it reusable.

Write {{target}} or {{port}} in a command. Open it to enter values, review the preview, and copy. Values are substituted literally; quote them as your shell requires. Recall never executes commands.

04

Keep a copy.

Your edits live in this browser’s local storage, not in GitHub. Export backups regularly; clearing browser data removes local commands. Import/export transfers your collection between devices. No accounts, remote sync, or LLM API keys are required.

The initial commands are examples. Start fresh whenever you’re ready.
